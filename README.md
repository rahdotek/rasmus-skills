# rasmus-skills

Min personlige marketplace til Claude. Hver post peger på den originale kilde på GitHub, så nye versioner kommer automatisk.

## Installér

**Claude Code:**

```
claude plugin marketplace add rahdotek/rasmus-skills
```

Slå derefter automatisk opdatering til: `/plugin` → Marketplaces → rasmus-skills → Enable auto-update.

**Claude-appen:** Customize → Plugins → tilføj marketplace fra GitHub → `rahdotek/rasmus-skills`.

## Tilføj eller fjern en skill

Ret `.claude-plugin/marketplace.json`: tilføj en post, der peger på skillens GitHub-repo, eller slet posten.
